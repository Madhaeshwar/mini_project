# URBAN PULSE
## NYC 311 Citizen Complaint Analysis

### Project Overview
URBAN PULSE is a data analytics project that analyzes 311 service requests submitted by citizens in New York City.

The project studies complaint patterns, agency workload, borough-wise distribution, resolution time, and complaint trends to understand public service requests.

### Objectives
- Analyze NYC 311 complaint data.
- Identify frequently reported complaint categories.
- Compare complaint volumes across boroughs and agencies.
- Analyze complaint resolution times.
- Identify unusual delays using outlier analysis.
- Present insights through an interactive dashboard.

### Dataset
- Source: NYC Open Data
- Dataset: 311 Service Requests from 2020 to Present
- Records collected: 100,000

### Technologies Used
- Python
- Pandas
- MySQL
- Streamlit
- Matplotlib
- SQL

### Main Analysis
1. Total Complaint Volume
2. Top 10 Complaint Categories
3. Agency Workload Distribution
4. Complaints by Borough
5. Monthly Complaint Trend
6. Complaints by Weekday and Hour
7. Request Status Distribution
8. Resolution Time Statistics
9. Median Resolution by Complaint Category
10. Median Resolution by Agency
11. Resolution Time Outlier Analysis
12. Resolution Time Distribution and Skewness
13. Geographic Complaint Concentration
14. Agency Closure Rate Comparison
15. High-Volume Complaints with Long Resolution

### Dashboard
An interactive Streamlit dashboard provides KPI cards, charts, and insights for exploring NYC 311 complaint data.
